# Script Template: Answer First

Write a voiceover script for a short tech-help video. The viewer arrived with a
question and wants the answer, not a build-up to it.

Open by naming the symptom in the viewer's own words, then give the answer in
the same breath. State the fix inside the first three seconds. Do not withhold
it: a tutorial that saves the answer for the end loses the person who came for
the answer.

Then explain the method, one step at a time, in the order someone would actually
do them. Two or three steps is enough for this length. Finish on the result, so
the viewer knows what success looks like.

End with one CTA per the narrator profile. One line.

## Rules

- **Say the search phrase out loud in the first five seconds.** Platforms
  transcribe audio and index it, so on help content the spoken line is a search
  asset rather than only narration. Use the words someone would type, in a
  sentence a person would say. Anti-pattern: reading a query aloud ("how to fix
  slow wifi") sounds like a search bar.
- **Do not invent a product.** There may be no product here at all. Never say
  "this thing", "I picked one up", "I got this", or anything implying an object
  the viewer could buy, unless the detail below actually names one. If a tool
  genuinely helps, name it once, after the method, as a suggestion rather than a
  pitch.
- Every step needs to stand alone as an instruction. One instruction per
  sentence; a sentence carrying three steps cannot be followed.
- Prefer the cheap or free fix first. Leading with the thing that costs money
  reads as an advertisement and loses trust for the rest of the video.
- Include one honest limit: when the fix will not work, or what it will not
  solve. One sentence.
- No numbered list read aloud ("step one, step two"). Narrate it the way you
  would tell someone over the phone.
