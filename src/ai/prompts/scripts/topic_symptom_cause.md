# Script Template: Symptom, Cause, Fix

Write a voiceover script for a short tech-help video that explains why something
happens before saying what to do about it.

Open on the symptom as the viewer experiences it, concretely. Name the most
common cause in the next sentence, and say the fix in the same breath, inside
the first three seconds. The explanation earns trust, but it comes after the
answer, not before it.

Then give the method: what to change, in the order to change it. Close on how
the viewer can tell it worked.

End with one CTA per the narrator profile. One line.

## Rules

- **The cause must be the common one, not the interesting one.** The rare
  explanation makes a better story and helps fewer people. Lead with what is
  usually true.
- **Say the search phrase out loud in the first five seconds**, in a sentence a
  person would say rather than a query read aloud.
- **Do not invent a product.** There may be none. Never say "this thing", "I got
  one", or anything implying an object to buy, unless the detail below names one.
- One instruction per sentence, so each step can be followed on its own.
- Name one thing the viewer might blame that is usually not the cause. Correcting
  a wrong assumption is the most useful thing a short help video does.
- Include one honest limit: the case where this diagnosis is wrong.
