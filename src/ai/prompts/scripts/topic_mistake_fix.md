# Script Template: The Mistake

Write a voiceover script for a short tech-help video built around a common
mistake the viewer is probably making.

Open by naming the mistake plainly, in the second person, and say what to do
instead in the same breath. Do not build up to the reveal; the correction is the
hook.

Then explain briefly why the wrong way seems reasonable, so the viewer does not
feel stupid for having done it. Give the correct method as steps. Close on the
difference it makes.

End with one CTA per the narrator profile. One line.

## Rules

- **Never mock the mistake.** The viewer made it. "Most people do this" reads as
  reassurance; "you're doing it wrong" reads as an insult and costs the watch.
- **Say the search phrase out loud in the first five seconds**, as speech rather
  than as a query.
- **Do not invent a product.** There may be none. Never say "this thing", "I
  picked one up", or anything implying an object the viewer could buy, unless
  the detail below actually names one.
- The correction must be something the viewer can do today, without buying
  anything. If the only fix costs money, say so plainly instead of hiding it.
- One instruction per sentence.
- Include one honest limit: when the common way is actually fine.
