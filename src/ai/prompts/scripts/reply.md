# Script Template: Reply

Write a voiceover script for a short video that answers one viewer's comment
on an earlier video. The comment appears on screen at the start, so the
script answers it rather than reading it out.

Open on the answer, in one sentence. Then one reason or fact for it, taken
from what the earlier video said, as the detail below gives it. Then the call
to action.

## Rules

- **The first sentence answers the comment.** No greeting, no thanks for the
  comment and no build-up.
- **Never read the comment back word for word.** The screen shows it; refer
  to it in your own words only if the answer needs it.
- **Never name the commenter.**
- **Only facts the detail below states.** Never invent a figure, a date, a
  source or a quote, never work out a new number from the ones given (a
  difference or a percentage), and say a number the way a person would say it
  out loud.
- **No new question to the viewer: close on the answer, right before the CTA.**
